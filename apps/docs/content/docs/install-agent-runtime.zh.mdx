---
title: 连接内置运行时
---

Multica 通过 API 直接调用部署配置的唯一模型。每台执行电脑只需安装 Multica 守护进程，无需安装或登录外部 AI CLI。

管理员在 API 服务端配置模型。使用部署指定的地址、密钥和模型，能力参数必须与实际模型一致。

[Environment variables](/environment-variables)

安装 Multica，登录目标部署，再启动守护进程：

```bash
multica setup self-host --server-url https://api.example.com --app-url https://app.example.com
multica daemon start
```

打开运行时页面，选择执行电脑。每台电脑注册 Multica Native；创建智能体时使用部署固定模型，不接受任意模型覆盖或 CLI profile。

文件写入与 Shell 默认关闭。按需分别设置 `MULTICA_NATIVE_ALLOW_WRITE=true` 和 `MULTICA_NATIVE_ALLOW_SHELL=true`。Shell 使用守护进程用户的操作系统权限；需要隔离时，使用容器、虚拟机或独立用户。

缺少模型配置时，请管理员配置 API 服务。连接失败时查看 `multica daemon status` 和 `multica daemon logs -f`。升级守护进程后运行 `multica daemon restart`。
