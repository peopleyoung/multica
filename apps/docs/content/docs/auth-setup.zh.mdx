使用独立用户名和密码注册。邮箱可选，不发送验证邮件；注册成功后立即登录。

## 账号规则

用户名不区分大小写，长度 3–32 位，以英文字母或数字开头，可包含英文字母、数字、点、下划线和短横线。密码长度为 12–72 字节，使用 bcrypt 哈希保存。

## 已有账号与密码恢复

旧用户需要管理员按原用户 UUID 初始化用户名和密码，以保留原工作区和历史。不能通过重新注册旧邮箱接管账号。不提供邮箱找回密码；忘记密码时由管理员使用同一命令重置。该命令不会撤销已存在的登录会话或 PAT。

```bash
read -r -s -p 'New password: ' MULTICA_ACCOUNT_PASSWORD
printf '%s' "$MULTICA_ACCOUNT_PASSWORD" | \
  bash scripts/dev-env.sh exec -- go -C server run ./cmd/account-admin \
    --user-id=USER_UUID --username=alice --password-stdin
unset MULTICA_ACCOUNT_PASSWORD
```

后端镜像也包含 `/app/account-admin`。上面的命令使用托管开发库；生产部署请使用对应的 `DATABASE_URL` 运行镜像内的命令。密码只从标准输入读取。关闭公开注册时，将 `--user-id=USER_UUID` 换成 `--create` 即可创建新账号，可选添加 `--email=alice@example.com`。联系邮箱仍为未验证状态。

## 注册范围控制

ALLOW_SIGNUP=false 关闭公开注册。可选邮箱未验证，邮箱白名单和邮箱邀请均不能作为新密码账号的注册授权；开放用户名注册时请清空邮箱白名单。已有用户保留工作区成员身份；新用户可通过明确分享的工作区链接加入。

## 会话有效期

浏览器使用 HttpOnly cookie，默认会话有效期为 30 天，持续使用时自动续期。AUTH_TOKEN_TTL 可调整期限。CLI/daemon 的 PAT 认证继续有效。

## 邮件与旧客户端

Resend/SMTP 仅为可选通知服务。联系邮箱不证明身份，也不会自动授予邮箱邀请权限。旧 send-code、verify-code 接口返回 HTTP 410，旧客户端需要升级。Google OAuth 接口保留供已有集成使用，新登录表单使用用户名和密码。
